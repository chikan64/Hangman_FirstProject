Добрый день! Виселица - первый проект (игра), написанный на языке Java.
Перед началом игры требуется ввести "старт", далее в консоли отобразится загаданное слово. Требуется угадать данное слово с помощью ввода букв. 
При достижении максимального количества ошибок (4 ошибки) игра завершается.
